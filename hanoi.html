The Prolog program

This is the actual clause set solving the puzzle and validating your moves, run by a real SWI-Prolog server over HTTP.

:- use_module(library(lists)).

hanoi(0, _, _, _, []) :- !.
hanoi(N, From, To, Via, Moves) :-
    N > 0,
    N1 is N - 1,
    hanoi(N1, From, Via, To, Moves1),
    hanoi(N1, Via, To, From, Moves2),
    append(Moves1, [move(From,To)|Moves2], Moves).

% used to check each move you make in "Play it yourself"
legal_move(_FromSize, 0).
legal_move(FromSize, ToSize) :- FromSize < ToSize.
?- hanoi(4, a, c, b, Moves), length(Moves, Len).
